# AppMaster

> AppMaster is a No-Code platform designed to help businesses create production-level applications with source code generation: backend, web, and native mobile apps.

AppMaster generates real source code (Go backend, Vue web apps, native Kotlin/SwiftUI mobile apps) from visual blueprints, and can export it. Applications can be hosted in the AppMaster cloud or deployed to your own infrastructure.
